# 硬件设计资料

本目录收录 STM32 控制板与双路 DRV8701 电机驱动板的 PDF 设计视图，用于在不安装 Altium Designer 的情况下查看原理图、PCB 布线和顶层丝印。

## STM32 控制板

| 文档 | 内容 |
| --- | --- |
| [主控板原理图](主控板原理图.pdf) | 控制核心、电源及外设接口连接 |
| [主控板布线图](主控板布线图.pdf) | PCB 器件布局、焊盘和走线 |
| [主控板丝印图](主控板丝印图.pdf) | 顶层丝印、接口标识和板框 |

## 双路 DRV8701 驱动板

| 文档 | 内容 |
| --- | --- |
| [驱动板原理图](驱动板原理图.pdf) | 双路电机驱动、电源与逻辑接口 |
| [驱动板布线图](驱动板布线图.pdf) | PCB 器件布局、功率回路和焊盘 |
| [驱动板丝印图](驱动板丝印图.pdf) | 顶层丝印、接口标识和板框 |

对应的可编辑 Altium Designer 文件位于 `hardware/controller-board/source/` 和 `hardware/dual-drv8701/source/`。

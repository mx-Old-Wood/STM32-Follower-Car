# 设计边界与已知限制

本项目以完成双车循迹、跟随和超车实验为目标，控制结构保留了入门阶段的直接实现方式。

## 软件结构

- 循迹转弯采用阻塞式 `while` 判断，转向动作期间的任务调度能力有限。
- 转弯过程不主动更新本车超声波，距离控制可能短暂沿用上一轮采样结果。
- `finish` 由标志线识别累加并通过复位清零，不包含掉电保存和异常恢复。
- 超车和让行采用固定速度与赛道经验参数，不包含轨迹规划。

## 数据可靠性

- 超声波和串口距离仅进行 `20~400 mm` 范围判断，没有连续确认或数字滤波。
- 串口距离没有超时失效机制，通信停止后可能保留上一帧有效状态。
- 串口解析未加入长度、非数字字符、缓冲区边界和校验和检查。

## 验证范围

- 固件已通过 Keil 全量编译，结果为 `0 Error(s), 0 Warning(s)`。
- 原始版本曾用于实车开发；当前整理版本没有完成最新硬件回归测试。
- PCB 源文件和 PDF 设计资料用于项目展示，未作为经过复核的量产文件发布。

这些边界限定了当前版本的适用范围，也构成后续非阻塞状态机、通信超时、距离滤波和参数整定功能的演进基础。

# 控制系统设计

## 总体结构

从车控制系统由循迹控制、距离外环和轮速内环组成。五路红外传感器负责赛道方向判断；距离反馈用于生成直行速度设定；双路编码器 PI 控制器将速度设定转换为电机 PWM 输出。

```text
超声波/串口距离 -> 距离 P 外环 -> 速度设定 -> 编码器 PI 内环 -> PWM -> 电机
五路红外传感器 -----------------> 转向与差速控制 ---------> 电机
```

距离外环作用于直行跟随阶段。转弯和循迹修正采用固定的左右轮差速参数，以保持原项目的赛道运行特性。

## 距离反馈选择

| 条件 | 相对位置 | 距离来源 | 控制方向 |
| --- | --- | --- | --- |
| 模式 1、模式 3 | 普通跟随 | 本车超声波 | 距离增大时加速 |
| 模式 2，`finish == 0` | 本车在后 | 本车超声波 | 距离增大时加速 |
| 模式 2，`finish == 1` | 本车在前 | 串口距离 | 距离增大时减速 |
| 模式 2，`finish >= 2` | 本车重新在后 | 本车超声波 | 距离增大时加速 |

阶段变化时，控制程序清除对应距离有效标志和 `Car_Found`，避免上一阶段的测距结果直接参与新阶段控制。

## 距离外环

距离控制参数定义于 `firmware/follower/User/Mode.h`：

| 参数 | 数值 | 含义 |
| --- | ---: | --- |
| `DISTANCE_MIN` | 20 mm | 有效距离下限 |
| `DISTANCE_MAX` | 400 mm | 有效距离上限 |
| `DISTANCE_AIM` | 200 mm | 目标跟车距离 |
| `BASE_SPEED` | 40 | 基础速度设定 |
| `MIN_SPEED` | 32 | 闭环速度下限 |
| `MAX_SPEED` | 45 | 闭环速度上限 |
| `DISTANCE_KP` | 0.07 | 距离比例系数 |

本车位于后方时，距离外环采用正向速度补偿：

```text
Speed_Set = 40 + 0.07 * (Local_Distance - 200)
```

本车位于前方时，串口距离表示后车与本车之间的间距，控制方向相反：

```text
Speed_Set = 40 - 0.07 * (Remote_Distance - 200)
```

两种计算结果均限制在 `32~45`。本车超声波距离有效且不大于 `180 mm` 时，运动控制切换为停车状态。

## 异常距离策略

距离数据只在 `20~400 mm` 范围内参与闭环。范围外数据不会更新当前有效距离，其对应速度策略如下：

| 场景 | 备用速度 |
| --- | ---: |
| 普通跟随阶段 | 40 |
| 第一次超车阶段，尚未检测到另一辆车 | 45 |
| 第二次让行阶段，尚未检测到另一辆车 | 35 |
| 当前阶段已经检测到车辆后再次丢失距离 | 40 |

该策略用于降低弯道中超声波偏转对速度设定的直接影响。

## 速度内环

TIM4 以 `100 us` 为中断周期，每累计 100 次中断完成一次轮速计算和 PI 更新，因此速度环周期为 `10 ms`。左右电机分别维护独立的增量式 PI 状态。

| 参数 | 数值 |
| --- | ---: |
| `Kp` | 1.85 |
| `Ki` | 0.40 |
| `Kd` | 0 |
| 输出范围 | `-65~65` |

速度设定为 0 时，电机 PWM、PI 输出和历史误差同步清零，停车状态不继续累积控制量。

## 关键实现位置

| 文件 | 职责 |
| --- | --- |
| `User/Mode.c` | 距离解析、阶段切换、距离控制和停车判断 |
| `Hardware/Infrared.c` | 循迹、标志线识别和 `finish` 更新 |
| `System/PID/PID.c` | 增量式 PI 运算 |
| `System/PID/Speed_Control.c` | 双电机速度控制与零速处理 |
| `System/Timer/Timer.c` | 编码器采样、轮速计算和速度环调度 |

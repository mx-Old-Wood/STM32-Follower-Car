# 双车串口通信协议

## 接口配置

| 参数 | 配置 |
| --- | --- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控制 | None |

## 帧格式

双车通信采用固定长度 ASCII 数据帧：

```text
@DDDDMMSS\r\n
```

| 字段 | 长度 | 定义 |
| --- | ---: | --- |
| `@` | 1 | 帧头 |
| `DDDD` | 4 | 另一辆车发送的距离，单位 mm |
| `MM` | 2 | 工作模式 |
| `SS` | 2 | 运行状态标志 |
| `\r\n` | 2 | 帧尾 |

示例帧：

```text
@02000201\r\n
```

该帧表示距离 `200 mm`、模式 `2`、状态值 `1`。

## 接收流程

USART1 中断以 `@` 作为接收起点，以 `\r\n` 作为结束标志。完整帧到达后置位接收标志，上层按照 `4 + 2 + 2` 位数字分别解析距离、模式和状态。

串口距离位于 `20~400 mm` 时标记为有效。控制程序同时根据状态字段执行以下动作：

| 条件 | 行为 |
| --- | --- |
| `Stop == 2` | 电机停止，持续等待新状态 |
| `Stop == 0`、距离有效且 `Remote_Distance <= 250` | 电机停止，蜂鸣器开启 |
| 其他状态 | 进入距离控制与循迹流程 |

## 协议边界

当前协议面向固定格式、低通信负载的双车实验场景，没有加入校验和、序号、字段类型检查和接收超时。发送端与接收端使用相同的固定帧定义。
